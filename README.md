# eqnovia-sun-spark

A TypeScript-based project with styling and scripting capabilities.

## Overview

This project leverages modern web technologies including TypeScript, CSS, and JavaScript to deliver a robust application experience.

## Technology Stack

- **TypeScript** (97.5%) - Primary language for type-safe development
- **CSS** (2.1%) - Styling
- **JavaScript** (0.4%) - Scripting

## Getting Started

### Prerequisites
- Node.js and npm installed

### Installation

```bash
git clone https://github.com/Bourzguifatimazahra/eqnovia-sun-spark.git
cd eqnovia-sun-spark
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
