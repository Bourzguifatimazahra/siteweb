## 🚀 Démarrage Rapide

### Prérequis

- [Node.js](https://nodejs.org/) >= 18
- [Bun](https://bun.sh/) (recommandé) ou npm

### Installation

```bash
# Cloner le dépôt
git clone https://github.com/Bourzguifatimazahra/eqnovia-sun-spark.git

# Accéder au dossier
cd eqnovia-sun-spark

# Installer les dépendances (avec Bun)
bun install

# Ou avec npm
npm install
```

### Développement

```bash
# Lancer le serveur de développement
bun run dev

# Ou avec npm
npm run dev
```

Le site sera disponible sur `http://localhost:3000`

### Build Production

```bash
# Construire pour la production
bun run build

# Prévisualiser le build
bun run preview
```

### Linting & Formatage

```bash
# Vérifier le code
bun run lint

# Formater le code
bun run format
```

## 📁 Structure du Projet

```

├── public/              # Fichiers statiques
├── src/
│   ├── components/      # Composants React
│   │   └── site/        # Composants du site
│   ├── lib/             # Utilitaires (i18n, etc.)
│   ├── routes/          # Pages (TanStack Router)
│   ├── styles.css       # Styles globaux (Tailwind)
│   ├── start.ts         # Point d'entrée client
│   └── server.ts        # Point d'entrée serveur
├── vite.config.ts       # Configuration Vite
├── tsconfig.json        # Configuration TypeScript
└── package.json         # Dépendances
```
